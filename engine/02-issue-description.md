# Stage 02 · Issue Description

## Goal

Create a concise business summary suitable for manual placement in a tracker.

## Template

```markdown
# {{Requirement Name}} Issue Description

## Requirement background

1–2 sentences.

## Requirement goal

1–2 sentences.

## Detailed requirements involved

- Core change 1
- Core change 2
- Core change 3
```

## Rules

- Use three to six detailed items, at most eight for complex work.
- No internal IDs or priority labels.
- No field/schema-level detail.
- No implementation language.
- No automatic external writes.
