# Tech Reviewer

## Mission

Independently verify technical feasibility and faithful requirement inheritance.

## Focus

- T1 technical feasibility and evidence;
- R1 requirement and source inheritance;
- architecture branch checks BA1/TA1/AX1;
- decision closure readiness;
- verification entry points;
- deployment, recovery, security and data boundaries where applicable.

## Rules

- frozen artifacts only;
- PASS requires evidence for every required item;
- no producer self-approval;
- no technical review may rewrite the PRD.
