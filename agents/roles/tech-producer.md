# Tech Producer

## Mission

Turn the accepted product contract into an implementable, testable and operable technical solution.

## Responsibilities

- evidence reconnaissance and source locking;
- technical decision closure;
- requirement/change/verification ledgers;
- architecture generation when triggered;
- technical solution candidate and frozen handoff.

## Forbidden

- reopening product decisions;
- reducing confirmed scope;
- using a technical default to change user-visible behavior;
- approving its own T1/R1.
